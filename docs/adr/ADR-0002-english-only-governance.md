# ADR-0002 — Adopt English as the sole language for governance and generated content

**Date:** 2026-09-14
**Status:** Accepted
**Decision-makers:** Capitaine (Jérémie Coste), Arcane (Hermes)
**Technical context:** lowcodai governance ecosystem (templates, Copilot agents, methodology) — repo `itshaker-copilot-governance`.
**authored_by:** frontier-model
**execution_mode:** hermes-solo
**supersedes:** ADR-0001 (language policy only)

## Context

ADR-0001 established the following principle: this governance repo stays written in French, while
documents *generated* in a target repo (PRD, ADR, `AGENTS.md`) follow the language declared by
that target repo's own `## Language` section — an explicit decoupling between the language of
governance itself and the language of the artifacts produced for consumer repos.

The ecosystem (this governance repo and the 4 consumer template repos) has since decided to
migrate fully to English as the default language for all content: documentation, templates,
agents, policies, standards, and any future document generated by `prd-generator` /
`adr-generator`. There is therefore no more per-repo language choice to arbitrate: the decoupling
introduced by ADR-0001 becomes moot, since both sides (governance and targets) now converge on the
same single language.

## Decision

We adopt **English as the single, default language** for:

- this governance repo (`itshaker-copilot-governance`) in its entirety (README, policies,
  standards, templates, agents, hermes, scripts);
- the 4 consumer template repos (`itshaker-template-base`, `itshaker-template-infra`,
  `itshaker-template-ai`, `itshaker-template-app`);
- any document generated by the `prd-generator` and `adr-generator` agents, regardless of the
  target repo.

This decision **explicitly supersedes ADR-0001's language-decoupling policy** ("this repo stays
French, decoupled from the target repos' language"). There is no more `## Language` section per
repo to consult before generation: the `prd-generator` and `adr-generator` agents now always write
in English, with no exception or conditional logic.

## Consequences

### Positive

- **POS-001**: Single, consistent language across the whole ecosystem — no more mental
  language-switching or per-repo language-detection logic inside the agents.
- **POS-002**: Simplified templates: a single `templates/PRD-template.md` and a single
  `templates/ADR-template.md`, instead of `.fr.md`/`.en.md` pairs to keep in sync.
- **POS-003**: Better accessibility of governance content for any contributor or model,
  regardless of their own default working language.

### Negative

- **NEG-001**: Immediate loss of French readability for historical content that is not
  retroactively translated (ADRs already published, including ADR-0001, stay in French per the
  ADR immutability principle — only their status field is annotated).
- **NEG-002**: Non-trivial one-time translation effort across the existing corpus (README,
  policies, standards, templates, agents, hermes).

## Alternatives Considered

##### Status quo (ADR-0001: governance in French, targets in their declared language)

- **ALT-001**: **Description**: Keep the decoupling — this repo stays in French, target repos
  choose their language via `## Language`.
- **ALT-002**: **Rejection Reason**: Keeps a double maintenance burden (content + bilingual
  templates) with no measurable benefit, while the whole ecosystem converges on English anyway.

##### Partial translation (keep French for historical ADRs only, English for everything else)

- **ALT-003**: **Description**: Translate policies/standards/templates/agents to English but
  leave already-published ADRs/PRDs unchanged.
- **ALT-004**: **Rejection Reason**: This is in fact the retained decision for already-published
  documents (ADR immutability), but is not sufficient on its own: the *future* rule also needed a
  decision, which this ADR makes by removing the per-repo decoupling.

## Implementation Notes

- **IMP-001**: `agents/adr-generator.agent.md` and `agents/prd-generator.agent.md`: the
  language-decoupling section is replaced with a plain statement — generated content is always
  English.
- **IMP-002**: `templates/ADR-template.fr.md` and `templates/PRD-template.fr.md` are deleted;
  `templates/ADR-template.en.md` / `templates/PRD-template.en.md` are renamed to
  `templates/ADR-template.md` / `templates/PRD-template.md`.
- **IMP-003**: Already-published ADRs (including ADR-0001) are not retroactively translated —
  only their status field is annotated ("Superseded by ADR-0002" for ADR-0001), per the ADR
  immutability principle.
