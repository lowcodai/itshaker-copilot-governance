# Standards — Documentation

## Required files in every project

| File | Description | Location |
|---------|-------------|-----|
| `README.md` | Description, quick start, links | Root |
| `CHANGELOG.md` | Version history (Keep a Changelog) | Root |
| `BACKLOG.md` | Project epics and stories | Root |
| `ROADMAP.md` | Vision and goals by version | Root |
| `AGENTS.md` | Copilot agents available in the project | Root |
| `CONTRIBUTING.md` | Contribution guide | Root |
| `SECURITY.md` | Security policy and reporting | Root |
| `LICENSE` | Project license | Root |
| `docs/adr/` | Architecture Decision Records | docs/ |
| `.github/copilot-instructions.md` | Copilot instructions for the project | .github/ |

## Architecture Decision Records (ADR)

Format: `ADR-XXXX-title-in-kebab-case.md`

Structure of an ADR:
```markdown
# ADR-XXXX — Decision title

**Date:** YYYY-MM-DD
**Status:** Proposed | In Progress | Accepted | Rejected | Deprecated | Superseded by ADR-YYYY
**Decision-makers:** <list>

## Context
## Decisions
## Consequences
## References
```

First ADRs to create:
- `ADR-0001` — Initial project decisions (generated by `init-adr.sh`)
- `ADR-0002` — Technical stack choice

## CHANGELOG

[Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format:
```markdown
## [Unreleased]
### Added
### Changed
### Deprecated
### Removed
### Fixed
### Security
```

## BACKLOG

Recommended structure:
- **Epics** — large units of business value
- **Stories** — deliverable units of an Epic
- **Icebox** — unplanned ideas

## ROADMAP

Recommended structure by version:
```markdown
## v0.1-alpha — Goal: ...
- [ ] Story 1
- [ ] Story 2

## v1.0 — Production Ready
- [ ] ...
```
